# Lesson 04 – Git Basics

This lesson introduces the basic concepts and commands of Git.

## Topics
- Initialize a Git repository (`git init`)
- Check repository status (`git status`)
- Stage changes (`git add`)
- Create commits (`git commit`)
- View commit history (`git log`)
- Compare changes (`git diff`)
- Restore uncommitted changes (`git restore`)
- Remove tracked files (`git rm`)
- Clone a repository (`git clone`)
- Connect local repo to GitHub (`git remote add origin`)
- Push changes to GitHub (`git push`)
- Pull changes from GitHub (`git pull`)
- Use `.gitignore`
- Write commit messages with Conventional Commits

## Learning Goal
After completing this lesson, you should be able to:
- Understand how Git tracks project history.
- Use the most common Git commands.
- Manage a local Git repository.
- Push and pull code with GitHub.
- Write clear and meaningful commit messages.
